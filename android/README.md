# JW Quiz — Android

WebView shell that packages the immersive web experience (Quiz / Rebus 3D / Avventura).

## Sync web assets into the APK

From repo root:

```powershell
python tools/sync_android_www.py
```

This copies `webapp/` → `android/app/src/main/assets/www/`. That folder is **gitignored** (generated). Always sync before building the APK.

## Build (Android Studio)

1. Open the `android/` folder in Android Studio
2. Let Gradle sync
3. Run on emulator or device

Optional CLI (requires Android SDK + `gradlew` wrapper generated by Android Studio once):

```powershell
cd android
.\gradlew assembleDebug
```

## Notes

- Offline-first: `file:///android_asset/www/index.html`
- CDN Three.js still needs network on first load of WebGL mode; CSS fallback works offline
- Same photorealistic assets as desktop (`Resources/`) and web (`webapp/assets/`)
